# Angel Rodriguez — Portfolio

A responsive React portfolio featuring my experience, projects, and technical skills. The content follows the resume at `public/Angel_resume.pdf`.

## Run locally

```bash
npm ci
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

Built with React and Vite. The production site is deployed on Vercel at [angelrod.work](https://angelrod.work).
